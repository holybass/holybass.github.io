HOLY MESHACK — PERSONAL PORTFOLIO

CONTENTS
- index.html: Home, About, Projects and Contact sections
- style.css: Responsive dark, modern styling
- script.js: Mobile navigation and current-year footer
- cv-template.html: Editable CV template

VIEW LOCALLY
1. Extract the ZIP file.
2. Open index.html in a modern browser.
3. Internet access loads the optional Google Fonts; the site otherwise works offline.

PERSONALIZE
- The circular HM avatar is a placeholder. Replace it with your own profile photo when ready.
- Add your social links, education, and verified project details when available.
- The CV is a template, not a completed CV. Fill in the placeholders before sharing.

PUBLISH
Upload the extracted folder to a static host such as GitHub Pages or Netlify.
The website is front-end only and does not require a server.
